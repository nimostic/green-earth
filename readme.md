# 🌍 Green Earth  
*A web application promoting environmental sustainability*

## 📌 Overview  
**Green Earth** is a web application designed to inspire environmental consciousness and promote sustainability. Users can browse different categories of trees and add them to a virtual shopping cart—symbolizing their contribution toward combating deforestation.

Built using **HTML**, **Tailwind CSS**, and **JavaScript**, the app provides a simple, responsive, and engaging interface that encourages users to explore and support greener initiatives.

---

## ✨ Features  
- 🌱 **Browse Tree Categories**  
  Explore multiple types of trees organized by categories.

- 🛒 **Add to Virtual Cart**  
  Symbolically add trees to your shopping cart to show support for reforestation.

- 🔍 **Search by Categories**  
  Quickly filter and find trees based on category selections.

- ⚡ **Responsive & Modern UI**  
  Built with Tailwind CSS for clean and fast performance.

- 💡 **Awareness-Focused Experience**  
  Encourages users to participate in environmental conservation.

1. Download or clone the repository

4. Enjoy the app — no server setup needed

---

## 🎯 Purpose  
The goal of **Green Earth** is to raise awareness about deforestation and inspire individuals to take symbolic action toward environmental protection. By “adding trees to a cart,” users reflect on the importance of reforestation and sustainability.
